# Mechanik Truck

Облачная FMS-система управления автопарком в эстетике macOS.

## Стек

- Next.js 16 (App Router) + TypeScript
- Tailwind CSS 4
- Lucide icons
- Клиентские демо-данные (без бэкенда)

## Модули MVP

- Обзор (KPI, лента событий)
- Автопарк
- Топливо
- Сервис / ТО
- Осмотры
- Поездки / путевые листы
- Склад
- Отчёты
- Настройки (тема, тарифы)
- ⌘K command palette
- Light / Dark mode

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

Страница входа: [/login](http://localhost:3000/login).

## Скрипты

- `npm run dev` — разработка
- `npm run build` — production-сборка
- `npm run start` — запуск production
- `npm run lint` — ESLint
